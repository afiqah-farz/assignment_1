# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a FYP student, I want to enter my skills and project interests and view recommended supervisors, so that I can choose a suitable supervisor for my project.
2. As a lecturer, I want to update my expertise and research areas, so that students can view my latest information when choosing a supervisor.
3. As a FYP student, I want to submit a supervision request to my preferred lecturer, so that the lecturer can view my request.
