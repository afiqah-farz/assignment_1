# Requirements

## Functional requirements (what the system must DO)
1. The system shall students to enter and update their skills and project interests.
2. The system shall allow lecturers to manage their profiles, expertise, and research areas.
3. The system shall allow administrators to manage user accounts and FYP information.
4. The system shall calculate a matching score for each lecturer based on the selected criteria.
5. The system shall display eligible supervisors in order of their matching scores, from highest to lowest.
6. The system shall allow students to view lecturer profiles.
7. The system shall allow students to submit supervision requests to their preferred supervisors.
8. The system shall allow lecturers to accept or reject supervision requests.
9. The system shall allow authorized users to manage FYP titles, reports, and progress updates.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display the recommendation list within 5 seconds when ranking up to 100 eligible lecturer records.
2. The system shall require users to log in before accessing the system.
3. The system shall allow users to find the lecturer profile page within 5 seconds during testing.
4. The system shall successfully process 20 valid recommendation requests without error during testing.
