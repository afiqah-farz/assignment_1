# FYP Supervisor Recommendation System Using Multi-Criteria Decision Making

A web-based system that helps FYP students compare and rank potential supervisors based on selected criteria.

## Problem statement
Students at FSKM, UiTM Shah Alam, might have trouble selecting a suitable supervisor for their Final Year Project because they have to compare each lecturer individually with their own expertise and research interests. This process takes more time when the information is difficult to compare. Previous research has explored systems that help students select a suitable thesis and FYP supervisor (Aklani & Jacky, 2022; Sari et al., 2021; Tam & Noryusliza Abdullah, 2025). Therefore, this project proposes a system that helps students compare and rank suitable potential supervisor based on selected criteria.
