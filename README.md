# FYP Supervisor Recommendation System Using Multi-Criteria Decision Making

## Problem statement
Students at FSKM, UiTM Shah Alam, might have trouble selecting a suitable supervisor for their Final Year Project because they have to compare each lecturer individually with their own expertise and research interests. This process takes more time when the information is difficult to compare. Previous research has looked into the use of a recommendation system to help students in choosing a suitable supervisor (Aklani & Jacky, 2022).
